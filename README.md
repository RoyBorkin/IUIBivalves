# סקר צדפות קודחות – IUI Bivalves

אתר סטטי למשימת הסקר של צדפות קודחות (Leiosolenus) באלמוגים חיים מול המכון הבין־אוניברסיטאי באילת.
הכתובת: https://royborkin.github.io/IUIBivalves/

## מה יש באתר
- מפה תלת־ממדית של החוף והקרקעית, עם כל נקודות הציון מהמשימה הקודמת (סיכה לכל נקודה, עם המידע והתמונות שלה).
- נקודת היציאה היא גליל בקוטר 50 ס״מ במרכז מסגרת 3 × 3 מ׳, בעומק 9 מ׳, שני שליש מהדרך מהמזח להביטט. ממנה יוצאים שני אזורי חיפוש: צמד צפון (רועי וגאיה: דולפין, תמנון, צב) וצמד דרום (מוריה ונעמה: לוויתן, דג ליצן).
- לכל אלמוג: מודל תלת־ממדי (כשיש), המצוף, תמונות, אזימוט ומרחק מנקודת היציאה (מחושבים מה־GPS), קרקע וצבע.
- שישה מצופים בצורת חיות ים, עם לוגו ומודל תלת־ממדי לכל אחד. כל מצוף מסמן אלמוג אחד.
- תצוגת לילה: הקרקעית כהה והסטיקלייטים זוהרים.
- שש מצגות: מטרת המשימה, צוות, תכנון המשימה, צלילת יום ושנירקול, צלילת לילה, מסקנות ותוצאות.
- בתכנון המשימה יש כפתור להדפסת דפי רישום, דף לכל מצוף.

## איך מכניסים את הנתונים אחרי הצלילות
כל הנתונים נמצאים בקובץ אחד: `js/findings.js`.
לכל אלמוג ממלאים את השדות (עומק, מספר חורים, שטח פנים, בדיקות פלואורסצאין ביום ובלילה, אור, קרקע, זרם, נ.צ. ועוד) ומשנים את `found` ל־`true`.
האתר מחשב לבד את הצפיפות ואת אחוז הצדפות הפעילות, ובונה את הטבלאות והגרפים במצגת "מסקנות ותוצאות".

- תמונות: לשים בתיקייה `assets/photos` (עם גרסה קטנה בסיומת `-s`), ולהוסיף ל־`photos` של האלמוג.
- מודל פוטוגרמטרי: קובץ `.glb` בתיקייה `assets/models`, או קישור ל־Sketchfab, בשדה `model3d`.
- מסקנות ותובנות: במערכים `CONCLUSIONS` ו־`LESSONS` באותו קובץ.
- תאריך ושעות: ב־`SCHEDULE`.

## פוטוגרמטריה
המודלים של הדולפין והתמנון (`assets/models`) נבנו מתמונות צלילת היום בסקריפטים שבתיקייה `tools/photogrammetry`
(שחזור מצלמות, מפות עומק, איחוד למשטח, צביעה מהתמונות, וקנה מידה לפי גודל הייחוס).
לצב, ללוויתן ולדג הליצן לא התקבלה צורה אמינה. אפשר לבנות להם מודל בתוכנה ייעודית (למשל Metashape, RealityCapture או 3DF Zephyr),
לייצא ‎.glb, לשים ב־`assets/models` ולכתוב את שם הקובץ בשדה `model3d`.

## תצוגת דוגמה
הוספת `?demo=1` לכתובת ממלאת נתוני דוגמה (לא אמיתיים), כדי לראות איך האתר ייראה עם נתונים.
באתר מופיעה אז תווית "נתוני דוגמה".

## העלאה ל־GitHub Pages
1. ליצור מאגר חדש בשם `IUIBivalves` בחשבון royborkin.
2. להעלות את כל התוכן של התיקייה הזו לשורש המאגר.
3. ב־Settings › Pages לבחור את הענף `main` ואת התיקייה `/ (root)`.

## קרדיטים
